Your keys stay yours.

HorseToga is a local Mac app — nothing runs through our servers. Your secrets live where macOS keeps its own.

  • API keys stored in the macOS Keychain — never on disk, never in plain text
  • Signed with Apple Developer ID & notarized, so Gatekeeper trusts every build
  • Updates are cryptographically signed — no tampered download can install
